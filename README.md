# ウラ読み商談

表情を読め。本音を引き出せ。

電話の声や、顧客の表情・しぐさから本音を読み取りながら商談を進める、営業ロープレ型のブラウザゲームです。
選択によって「テクニック発動」や「NG行動」の解説が入り、営業心理学と営業テクニックを遊びながら覚えられます。

## 遊び方

- `index.html` をブラウザで開くだけで遊べます（ビルド不要）
- 上のハートが自分への信頼。失言で減り、ゼロになると決裂
- 「心の壁」ゲージを崩しきると、相手が本気で話を聞き始める
- ヒアリングで聞き出した本音は「手帳」に貯まり、後半の強い選択肢が使えるようになる
- 第2話は、第1話をクリアすると遊べる

## 収録エピソード

| 話 | タイトル | 相手 | 状態 |
|---|---|---|---|
| 第1話 | 受話器の向こう | 母の家を相続し、売るか迷っている男性（テレアポ） | 完成 |
| 第2話 | はじめての訪問 | 同じ男性（初めての面談。約束は15分） | 完成 |
| 第3話 | 数字の重み | 同じ男性（査定額の提示） | 準備中 |
